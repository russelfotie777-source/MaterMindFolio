# Captures des projets

Dépose ici les captures d'écran des cinq projets qui n'ont pas encore de média : Fast Shipping, Batobaye Market, MboaMarkets, Shopitech et ArtVibeCamer. ZIRIS est déjà fait.

Nom de fichier : `projet-page-format.png`, par exemple `batobaye-accueil-mobile.png` ou `shopitech-admin-desktop.png`.

## Règles

- **Ordinateur** : navigateur en plein écran (touche F11), fenêtre d'environ 1440 px de large, sans onglets ni barre d'adresse.
- **Téléphone** : capture d'écran native du téléphone, notifications masquées.
- **Aucune donnée réelle** : pas de nom, téléphone, e-mail, adresse ou commande de vrais clients. Utilise un compte de démonstration, un formulaire vide ou des données de test.
- Attends que toutes les images de la page soient chargées.
- Garde le fichier original, sans retouche.

## Ce qu'il faut, par projet

| Projet | Captures |
|---|---|
| Fast Shipping | suivi de colis, demande de devis et back-office ; **pas l'accueil**, qui montre encore le contenu de démonstration du thème |
| Batobaye Market | 2 ou 3 écrans de l'application mobile (accueil, fiche produit, panier), le storefront sur ordinateur, l'administration React avec des données de test |
| MboaMarkets | accueil sur ordinateur et sur téléphone, une fiche produit, la gestion des produits dans l'administration |
| Shopitech | accueil de la beta sur ordinateur et sur téléphone, une fiche produit, l'administration |
| ArtVibeCamer | accueil sur ordinateur et sur téléphone, formulaire d'inscription vide, une fiche candidat publique, le tableau de bord avec des données de test |

Claude contrôle chaque capture, masque ce qui doit l'être et la recadre ; Codex l'intègre dans les belvédères.
